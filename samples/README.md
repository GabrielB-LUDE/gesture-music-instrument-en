# Your own sounds

Your own WAV files go in here; one subfolder per sound is only
a suggestion for keeping things tidy - names and layout are up to you.

For a file to actually be used, it must also be registered in
`src/audio/sample_files.py`. That file also contains the
complete instructions and the list of bank names (kick, clap, hats,
sub, acid, lead, stab, sweep, ...).
